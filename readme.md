# Validador de acciones de vivienda CONAVI

Este proyecto realiza la validacíon de las aprobaciones y modificaciones de acciones de vivienda acorde a las reglas de opreacion 2026, actualmente tiene disponible dos opciones:

    [1] Aprobaciones S100

    [2] Modificaciones S100
Se encuentra en desarrollo los módulos de aprobaciones y modificaciones para el esquema de Vivienda para el Bienestar.

## Uso del validador
1. Instalar Anaconda Navigator
2. Agregar el path a las variables de entorno del sistema
    * La  ruta debe de ser C:\Users\%USERNAME%\AppData\Local\anaconda3\condabin
3. Validar la instalación de las dependencias, el listado se encuentra en el 
documento **requirements.txt**
4. Una vez validado que las dependencias han sido instaladas, se puede ejecutar el validador mediante el archivo **ejecutar_validador.bat**
